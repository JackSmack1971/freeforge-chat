<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser UI → localStorage | archived conversations are read from and written to browser storage, so archive contents must be validated before render or restore. |
| drawer UI → live chat shell | restore actions replace the active conversation state and must not happen without the explicit replacement gate when draft text exists. |
| browser storage → render surface | history rows and previews are derived from stored conversation content and must stay text-only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering / Information Disclosure | `freeforge/src/features/history.js` archive render path | mitigate | Validate archive entry shape before use, render previews as text only, and never feed archive previews into the markdown renderer. |
| T-02-02 | Tampering | restore action and replace-confirm surface | mitigate | Require explicit replacement confirmation when composer text exists; otherwise restore immediately per D-03 and D-04. |
| T-02-03 | Denial of Service | localStorage archive growth | mitigate | Cap the archive at 10 entries and prune oldest-first so the drawer cannot grow without bound. |
| T-02-SC | Tampering | local tooling / package installs | accept | No package installs or dependency changes are in scope for this phase. |
</threat_model>
