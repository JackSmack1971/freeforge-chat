### 2026-07-04 - Create the ledger early

- Evidence: the current checkout had no `.team_experience.md` at the repo root when this issue was opened.
- Lesson: seed and commit the ledger before starting another multi-agent workflow so future runs do not begin from zero institutional memory.

### 2026-07-04 - Use worktrees when the root checkout is dirty

- Evidence: this repo already had unrelated modified planning artifacts, so the issue branches in this session were isolated under `.worktrees/`.
- Lesson: when the shared checkout is dirty, branch in a worktree instead of stacking issue work on top of unrelated local changes.

### 2026-07-04 - Treat timeout and context-pressure as a checkpoint signal

- Evidence: `.session-feedback/report.md` shows `timeout` and `context_pressure` as recurring categories.
- Lesson: checkpoint state, narrow retries, and avoid re-running the same command shape when the run starts to churn.

### 2026-07-04 - Prefer the GitHub API when CLI label parsing is ambiguous

- Evidence: `gh issue edit` rejected `status:in-progress` during this session, while `gh api repos/JackSmack1971/freeforge-chat/issues/*/labels -F labels[]=status:in-progress` worked.
- Lesson: fall back to the REST endpoint when `gh` flag parsing gets in the way of the task.
